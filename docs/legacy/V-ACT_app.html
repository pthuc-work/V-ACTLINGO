📘 Tóm Tắt Công Thức Câu Điều Kiện (Chuyên Đề 15)

Loại điều kiện Cấu trúc chuẩn Dạng đảo ngữ & Lưu ý
Loại 0
Sự thật hiển nhiên		 If + S + V(s/es), S + V(s/es) Dùng cho quy luật tự nhiên, thói quen.
Loại 1
Có thật ở hiện tại/tương lai		 If + S + V(hiện tại), S + will/can/may/must + V(bare) Đảo ngữ: Should + S + (not) + V(bare), S + will + V
Loại 2
Trái với hiện tại		 If + S + V2/ed (were), S + would/could + V(bare) Đảo ngữ: Were + S + (not) + (to V), S + would + V
Loại 3
Trái với quá khứ		 If + S + had + P2, S + would/could + have + P2 Đảo ngữ: Had + S + (not) + P2, S + would + have + P2
Trộn 3 – 2
Nguyên nhân QK → Kết quả HT		 If + S + had + P2, S + would + V(bare) + now/today Đảo ngữ: Had + S + (not) + P2, S + would + V(bare) + now
Trộn 2 – 3
Bản chất HT → Kết quả QK		 If + S + V2/ed (were), S + would + have + P2 Đảo ngữ: Were + S + ..., S + would + have + P2
Cấu trúc mở rộng • Unless = If ... not
• Without / But for + N/V-ing		 • ĐK2: If it weren't for / Were it not for + N
• ĐK3: If it hadn't been for / Had it not been for + N

📲 Đóng Gói Web App & Tạo Shortcut Trên Máy

Trạng thái bộ nhớ dữ liệu: IndexedDB + LocalStorage đã kích hoạt (Tự động lưu vĩnh viễn)

Bước 1: Lưu tệp ứng dụng về máy tính
Bấm nút "⬇️ Tải tệp App độc lập (.html)" bên dưới để lưu tệp về một thư mục cố định trên máy (ví dụ: D:\HocTap\VACT_Hub.html). Mở tệp này bằng Google Chrome hoặc Microsoft Edge để dữ liệu luôn được lưu cố định theo đường dẫn tệp.

Bước 2: Tạo Shortcut ngoài màn hình Desktop (Mở như phần mềm)
• Trên Chrome / Edge (Windows & macOS): Nhấn biểu tượng menu ⋮ (góc trên bên phải trình duyệt) → chọn Lưu và chia sẻ (Save and share) → Tạo lối tắt (Create shortcut...) → Tích chọn "Mở dưới dạng cửa sổ (Open as window)" → Nhấn Tạo (Create).
• Sau khi tạo, biểu tượng V-ACT Hub sẽ xuất hiện ngay trên Desktop và thanh Taskbar, mở lên như một ứng dụng độc lập không có thanh địa chỉ trình duyệt.

Bước 3: Tự động mở khi khởi động máy tính (Tùy chọn)
Nhấn tổ hợp phím Win + R → gõ shell:startup → nhấn Enter, sau đó chép biểu tượng Shortcut V-ACT Hub ngoài Desktop dán vào thư mục vừa mở.
